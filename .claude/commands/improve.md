Запусти круг улучшения Мартышки. Сделай задач: $ARGUMENTS (если пусто — 3).

1. Вызови агента `martyshka-reviewer` в режиме «что улучшить». Покажи брату его список задач коротко
   (по строке на задачу).
2. Для каждой задачи по порядку (не больше заданного числа):
   a. Вызови агента `martyshka-coder` с полным текстом задачи (проблема, доказательство, как должно быть,
      как проверить).
   b. Вызови `martyshka-reviewer` в режиме «приёмка»: дай ему задачу и отчёт Кодера.
   c. `НЕ ПРИНЯТО` — один раз верни Кодеру с замечаниями Проверяющего и снова на приёмку.
      Второй раз не принято — откати правки этой задачи (`git restore` по файлам Кодера, только его файлы)
      и переходи к следующей.
   d. `ПРИНЯТО` — сделай коммит этой задачи (сообщение по-русски: что исправлено и почему, с цитатой
      доказательства; в конце строка Co-Authored-By как обычно).
3. Живого бота Говорилки, окно и голосового помощника НЕ перезапускай без разрешения брата — в конце спроси.
4. В конце — короткий отчёт брату: по каждой задаче «сделано / откачено», коммиты, что ещё не проверено вживую.
