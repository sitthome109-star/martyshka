# Мартышка — карта проекта

Голосовой помощник для Windows 11 в духе Джарвиса + окно-чат с агентом. С 20.11.2026 мозг — **DeepSeek API** (flash/pro), голос — **Fish Audio API**, распознавание речи — **DeepSeek ASR**. На ПК только «ухо на имя» (Vosk), детектор речи (Silero) и вырезание фона (rembg). Генерации картинок и видео нет (убрана по просьбе брата).
Пользователь не программирует и пишет по-русски. Весь код пишет ассистент и объясняет простыми словами, без жаргона.
Пользователя в коде и инструкциях называют «брат».

Подробная история — в `ПЛАН.md`, последнее состояние и открытые проблемы — в `handoff.md`. Читай их только по необходимости.

## Запуск
- Python venv: `.venv` (Python, CUDA). Запуск без окна: `.venv\Scripts\pythonw.exe martyshka_main.py`.
  - С консолью для отладки — «Мартышка (с окном, для отладки).bat».
  - Текстовый чат без голоса — `chat.py` («Чат с Мартышкой.bat»).
- **Одно приложение: «Мартышка.exe» → `studio.py` (окно).** Голосовой помощник (`martyshka_main.py`, шар, уши) —
  отдельный процесс, его включает/выключает кнопка «Говорить» в окне (`VOICE_AUTOSTART` запоминает выбор).
  Ярлыки: Рабочий стол и Автозагрузка «Мартышка.lnk» (автозагрузка с `--autostart`). Иконка — шар (`studio/studio.ico`).
- Ключи `DEEPSEEK_KEY`, `FISH_KEY` — в `data/settings.json` (не в git). Без денег на DeepSeek мозг отвечает ошибкой 402.
- Ollama больше не нужна.
- Тестов нет. Проверяй прямыми скриптами в scratchpad, например `hands.run(...)`, а не всей программой.
- Журнал разговора — `data/журнал.txt`, ошибки — `data/ошибки.jsonl`.

## Железо
RTX 5070 12 ГБ, 32 ГБ RAM, экран 1920×1080 с масштабом 100%. Видеокарта теперь почти не нужна — всё в облаке.

## Модули (`martyshka/`)
| Файл | За что отвечает |
|---|---|
| `martyshka_main.py` | Главный цикл: имя «Мартышка» → слушать → мозг → дела → голос. Диктовка, тихий режим, `run_actions` + обходной путь (`NO_RECOVER`). Следит за `settings.json` (подхватывает на ходу), флажками `перезапуск.flag`/`выключить.flag` и сторожит бота Говорилки. |
| `deepseek.py` | **Вся связь с DeepSeek**: `stream`/`complete`/`ask`, `look` (картинка → flash), `transcribe` (ASR), `pick` (авто flash/pro), `balance`, переходник `Client()` в стиле старого ollama. **Экономия** (`ECONOMY`): всё после «=== Сейчас ===» в первой инструкции переносится в конец (перед последней репликой) — характер и переписка идут из кэша DeepSeek; старые результаты инструментов режутся до 2500 знаков; баланс < `ECONOMY_BALANCE` — «Авто» только flash. |
| `fish.py` | **Голос Fish Audio**: `speak` (PCM 24 кГц потоком), модели `fish.MODELS`: `s2.1-pro-free` (после 30.11.2026 сама → `s2.1-pro`), `s2.1-pro` и платная `drama-3` (кончились кредиты — 30 мин бесплатной); у Говорилки своя `GOVORILKA_FISH_MODEL`; `DRAMA_PICKS` — голоса, рекомендованные для Drama; **голос под настроение** `mood_pick` (`MOOD_VOICE`): метка `{драма}`, пение (`{поёт…}`) и злость ≥ `MOOD_ANGRY_FROM` — эта фраза через Drama 3 (в злости — `ANGRY_VOICE_ID`), остальное — обычной моделью, каталог голосов `data/голоса_fish.json` (официальные + популярные ru/uk/de/en), `search`. |
| `longmem.py` | **Долгая память на всех**: лента дня `data/память/лента/*.jsonl`, пересказы дней `дни.json`, люди `люди.json` (факты + злость 0–5 с остыванием). `context()` идёт в инструкции. `memory_import.py` — разовый перенос старых журналов. |
| `growth.py` | **Опыт — саморазвитие**: `data/память/опыт.json`. Уроки из меток `[УРОК: …]` (голос, Говорилка), инструмента `learn` (чат), разбора после каждой задачи агента (`reflect_task`) и разбора дня (`reflect_day`). `context(query)` — подходящие уроки в инструкцию; >160 — сжимает сам. |
| `settings_schema.py` | Все настройки для окна чата (вкладки Мозг/Характер/Голос/Уши/Агент/Шар/Система) и их сохранение. |
| `brain.py` | Мозг голоса: DeepSeek потоком (`self.model` = `pick()` на каждую фразу). Метки `[ДЕЛО: …]`, `[ТОН: n]` (злость), `[ЗАПОМНИ О: имя \| факт]`, эмоции голоса `{laughing}`. Перехватчики (`EXE_RE`, goto…) до модели. |
| `personality.py` | Инструкция мозгу: характер + `SOUL` (свобода решений, без лимита длины, мат на её усмотрение, подача голосом в стиле Drama 3: `{указание своими словами}`, звуки/паузы, парные `<whisper>…</whisper>` и др.; нарастающий характер; уроки) + дела; в конце — память, опыт, время, злость. |
| `style.py` | Манера общения: `bro` или `jarvis`. |
| `hands.py` (самый большой) | Все «дела»: словарь `ACTIONS` (он же уходит в инструкцию), `execute_all`, `last_failed`. |
| `agent.py` | Режим агента голоса: до 10 шагов со снимком экрана (DeepSeek flash видит). PowerShell — только после «да». |
| `vision.py` | Снимок экрана → DeepSeek flash; клики через UI Automation; `hotkey`. |
| `goto.py` | Быстрые пути: `steam://`, `ms-settings:`, `.msc` вместо кликов. |
| `ears.py` | Vosk ждёт имя, фразу распознаёт DeepSeek ASR; язык — `guess_language` по тексту. Режим диалога (`DIALOG_MODE`): только по имени, без «продолжения», пауза `DIALOG_SILENCE`, длинные фразы до `DIALOG_MAX_SECONDS`. |
| `voice.py` | Голос через Fish: очередь предложений → `fish.speak` → колонки. `{указание}` → `[указание]` для Fish, парные метки Drama 3 (`PAIR_TAGS`) проходят как есть (бесплатная s2.1 их понимает); `CueFilter`/`strip_cues` убирают всё с экрана. Темпа/выразительности в настройках нет — подачу решает сама. |
| `face.py` | Шар из точек поверх окон (отдельный процесс). Клик — открыть чат (`system.open_chat`), правая кнопка — меню. Цвет/размер подхватывает из `data/face.json` на ходу. |
| `config.py` | Все настройки по умолчанию. |
| `media.py` | Правка готовых фото и видео (фон, обрезка, сжатие…). Генерации нет: `draw()` отвечает, что не умеет. |
| `games.py`, `game_skeleton.html` | Мартышка пишет HTML5-игры и сама их тестирует. Игры лежат в «Документы\Игры Мартышки». |
| `exebuild.py`, `exe_host.cs` | Сборка игры в exe: csc.exe из .NET Framework + WebView2 (`tools/webview2`). |
| `web.py` | Поиск в DuckDuckGo, погода Open-Meteo, таблицы. |
| `telegram_bot.py` | Бот слушает только хозяина; сообщения идут в общую очередь. |
| `memory.py` | Факты о брате и история разговора (`data/`). |
| `commands.py` | Свои команды: одна фраза → несколько дел (`data/команды.json`). |
| `briefing.py` | Утренняя сводка: погода, напоминания, заряд устройств. |
| `calc.py` | Арифметика без модели. |
| `aula.py` | Заряд клавиатуры Aula F75 Max через HID. |
| `errlog.py` | Дневник ошибок. |
| `studio/` | **Окно чата** («Мартышка Студия.exe» → `studio.py`). `brains.py`: DeepSeekBrain — болтовня Flash, дела Flash+мысли, код/сложное Pro+мысли (режим Авто/Flash/Pro сверху окна, кнопка «Агент»); мысли (`reasoning`) хранятся в истории и возвращаются в API. `tools.py` + `devtools.py`: коннекторы (интернет, файлы, разработка: grep/glob/python/git/http/page_preview/фоновые процессы, команды, ПК, дела, память) и разрешения. `agent_loop.py`: цикл агента, контекст + долгая память. `app.py`: главное окно (voice_set, dictate 🎤, speak 🔊, pick_file 📎), крестик прячет (если голос работает), флажок `data/studio/показать.flag` с вкладкой. `ui/index.html`: весь интерфейс — дизайн как у «Морни» брата (вкладки сверху, «Мартышка✦», Чат/Говорить, дымчатый фон, фиолетовые пузыри); ход агента — ОДНА сворачиваемая строка в пузыре (шаги, мысли, план с галочками). План: `Chat._set_plan/_fix_plan/_finish_plan` (галочки сами, в конце — все ✓); защита от петель (`stuck`). **Самопроверка**: правила файлы (`WRITE_TOOLS`) и ничего не запустила после (`VERIFY_TOOLS`) — скрытое сообщение `SELF_CHECK`, до 2 раз за задачу. |
| `govorilka.py` | **Мартышка в «Говорилке»** (самодельный голосовой чат брата, `Desktop\govorilka.exe`). Вторая копия govorilka.exe с подменным `APPDATA` = `data/govorilka_bot/appdata` (ник «Мартышка (ИИ)»). Говорит голосом Fish (`GOVORILKA_VOICE_ID`) в VB-CABLE «CABLE Input» → микрофон копии. Слушает петлёй `GOVORILKA_LISTEN_DEVICE` → Silero → DeepSeek ASR. Мозг DeepSeek (flash по умолчанию). **Кто говорит** — `SpeakerWatch`: каждые 0,15 с снимок своего окна, у говорящего в списке голосовой комнаты имя фиолетовое; имена читает встроенный OCR Windows (`tools/ocr.ps1`, ru+en) в фоне — только когда поменялись строки списка (аватарки анимируются — их не учитывать!) и раз в 90 с; фраза приписывается тому, кто светился большую часть её времени; светились двое — побеждает тот, кто светился ОДИН (второй часто — чужой микрофон, слышащий колонки), иначе никому («говорили вместе»); `Listener` режет фразу, когда сменился говорящий (`speaker_now` = `SpeakerWatch.current`) → своя память и злость на каждого. Пауза перед ответом `QUIET_SENTENCE` 2 с. Кнопка «Начать диалог с Морни» = флажок `начать_с_морни.flag` (в нём JSON `{topic}` — тогда **дебаты**: `DEBATE`, `start_debate`, голосом «поспорь с Морни о …», 8 минут). **Быстрее**: `Prethink` — во время паузы (с `PRETHINK_AFTER` 0,6 с) мозг уже пишет ответ, первая фраза озвучивается заранее (`_presynth`/`_take_presynth`); продолжил говорить — заготовка выбрасывается. **Привет/пока** (`GOVORILKA_GREET`) по составу комнаты из `SpeakerWatch`. **Сама вмешивается** (`GOVORILKA_CHIME`): не чаще `CHIME_EVERY`, может ответить `[МОЛЧУ]`; в долгой тишине (`QUIET_TALK_AFTER`) сама заговаривает — `_speak_own`. Любимые темы людей: метка `[ИНТЕРЕС: имя | тема]`, `longmem.add_topic`, разбор дня; в карточке человека «любит говорить о». Песни про людей — из того, что о них помнит. Характер нарастающий: злость на каждого (`longmem.anger`), метки `[ТОН]`, `[КТО]`, `[ЗАПОМНИ О]`. Сидит всегда: перезапускает упавшую Говорилку, сторож в `martyshka_main` возвращает бота; «уйди с сервера совсем» = `ушла.txt`. Кнопки «Войти в голос»/«трубка» — по цвету на снимке окна, настоящий клик. Журнал: `data/govorilka_bot/журнал.txt`. |
| `system.py` | Одна копия программы, ярлыки, автозапуск, проверка Ollama. |

## Как добавить новое «дело»
1. В `hands.py` добавь запись в `ACTIONS` и функцию-исполнитель.
2. Если нужен быстрый перехват без модели — регулярка в `brain.py`.
3. Если повторять при неудаче не нужно — имя дела в `NO_RECOVER` в `martyshka_main.py`.
4. Без денег на DeepSeek проверяй с подменой `deepseek.stream` (пример — scratchpad `mock_test.py`).

## Правила (обязательно)
- Перед скачиванием спрашивать: что, откуда, какого размера.
- Личные данные не отправлять во внешние сервисы. `data/` в git не попадает (там история, журнал, токен бота).
- Завершать только проверенные процессы самой Мартышки и тестов.
- Удалять только в Корзину и с подтверждением.
- Свои клоны реальных голосов не создавать. Голоса из библиотеки Fish (включая похожие на известных людей) брат
  выбирает сам — это его решение (20.11.2026).
- Не слать клавиатуре Aula непроверенные команды.
- Тесты, которые жмут мышь и клавиши, запускать только когда нужное окно впереди.
- Неотключаемые границы характера (даже в ярости): без оскорблений по национальности, религии, полу, ориентации,
  внешности, здоровью; без угроз и подталкивания к самоповреждению; без чужих личных данных.
- Большие файлы (`hands.py`, `brain.py`, `face.py`, `media.py`) не читать целиком — ищи нужное место через Grep.
